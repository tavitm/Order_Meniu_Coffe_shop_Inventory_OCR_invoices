Program (subsol)

Backup și restaurare

Backup-ul conține doar datele meniului: categoriile (și dacă sunt afișate sau ascunse), produsele cu prețuri, descrieri și imagini, imaginea ofertei și setările. Codul site-ului nu este atins. Înainte de orice restaurare, starea curentă este salvată automat ca backup „Înainte de restaurare”.

Backup-uri pe server

Se creează automat unul la fiecare „Salvează” (se păstrează ultimele 30). Backup-urile manuale se păstrează până le ștergi.
